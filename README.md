# Global Population Dashboard
Data analytics dashboard for population, health, and economic growth indicators.

## Overview
Interactive Power BI dashboard with World Bank data.

## Features
- Population comparison
- GDP growth trends
- Life expectancy analysis
- Regional insights

## Data Source
World Bank Open Data (1990 - 2023)

## How to Use
1. Download the .pbix file
2. Open with Power BI Desktop
3. Explore the dashboards

## Requirements
Power BI Desktop (latest)
